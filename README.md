# 🚗 Diamond Motor Spares Website

A simple website built for a motor spares business to showcase products and services.

## 📌 Overview
This project is a basic informational website for a motor spares organization. It displays different categories of car parts and provides users with an easy way to explore available products.

⚠️ Note: This is not the official final version. An improved version will be developed later.

## 🚀 Live Demo
👉 https://diamondmotorspares.netlify.app/

## 🚀 Features
- Homepage with business overview  
- Separate pages for different motor spare categories  
- Simple navigation between sections  
- Contact form for customer inquiries  
- Clean and responsive layout  

## 🛠️ Technologies Used
- HTML  
- CSS  
- JavaScript
